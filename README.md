
## Basic C Programming Questions & Solutions  

This repository contains solutions to common C programming questions, ranging from beginner to intermediate levels.  
## Topics Covered

- **Basic Syntax**(Hello World, Input/Output)  
- **Control Statements** (if-else, switch-case)  
- **Loops** (for, while, do-while)  
- **Functions** (User-defined, Recursion)  
- **Arrays** (1D, 2D, Multi-dimensional)  
- **Pointers** (Basics, Pointer Arithmetic)  
- **Strings** (String Functions, Manipulation)  
- **Structures & Unions**  
- **File Handling** (Read/Write Operations)
